# Claim Plane papers

This directory indexes research publications associated with Claim Plane.
Published papers remain hosted by their archival source; the repository stores
citation metadata and links each publication to the corresponding reproducible
research workflow.

### Paper #2 — Claim Plane: Reliability Gains and the Limits of Selective Concurrency for Parallel Coding Agents

- Author: Maxim Nikolaev
- Submitted: 2 August 2026
- Subject: Software Engineering (`cs.SE`)
- arXiv: [2608.00947](https://arxiv.org/abs/2608.00947)
- PDF: [arXiv PDF](https://arxiv.org/pdf/2608.00947)
- DOI: [10.48550/arXiv.2608.00947](https://doi.org/10.48550/arXiv.2608.00947)
- Citation and reproduction notes: [claim-plane-confirmatory-2026](claim-plane-confirmatory-2026/README.md)
